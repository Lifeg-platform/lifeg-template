# 1. Abstract

Provide a concise summary of the proposal.

The abstract should explain the purpose of this LRFC in a few paragraphs.

---

# 2. Motivation

Explain why this proposal exists.

Describe:

- current limitations;
- opportunities for improvement;
- expected benefits;
- why this proposal should be considered.

---

# 3. Problem Statement

Describe the problem without proposing a solution.

Clearly define:

- what is wrong;
- who is affected;
- why it should be addressed;
- consequences of doing nothing.

---

# 4. Proposed Solution

Describe the proposed solution in sufficient detail.

Include:

- architecture overview;
- expected behavior;
- affected components;
- compatibility considerations;
- migration strategy (if applicable).

Use diagrams where appropriate.

Clearly distinguish facts from assumptions.

# 6. Discussion

Document the engineering discussion.

Include:

- technical comments;
- implementation concerns;
- security considerations;
- operational considerations;
- compatibility issues;
- performance considerations;
