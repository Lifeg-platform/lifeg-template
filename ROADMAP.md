# Release Strategy

Development follows an iterative release model.

Each completed milestone results in a new tagged release.

Repository versions follow Semantic Versioning (SemVer).

# Versioning Policy

This repository uses Semantic Versioning.

- Major versions introduce significant changes.
- Minor versions introduce backward-compatible improvements.
- Patch versions contain fixes and documentation updates.
