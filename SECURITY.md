# Purpose

This document defines the security policy for repositories within the Lifeg Platform organization.

Its purpose is to promote responsible vulnerability reporting and ensure timely resolution of security issues.

---

# Security Principles

The Lifeg Platform follows these security principles:

- Secure by Default
- Least Privilege
- Defense in Depth
- Documentation First
- Responsible Disclosure
- Reproducible Infrastructure

---

# Supported Versions

Only actively maintained versions receive security updates.

| Version | Supported |
|----------|-----------|
| 1.x | ✅ |
| 0.x | ✅ Active Development |
| < 0.x | ❌ |

---

# Reporting a Vulnerability

Please do not disclose security vulnerabilities publicly.

Instead:

1. Prepare a detailed description.
2. Include reproduction steps if possible.
3. Describe the potential impact.
4. Suggest mitigation if available.

---

# Response Process

Every reported issue follows this workflow:

1. Acknowledge the report.
2. Validate the vulnerability.
3. Assess severity.
4. Develop a fix.
5. Test the fix.
6. Publish the update.
7. Update documentation if necessary.

---

# Severity Levels

Security issues are classified as:

- Critical
- High
- Medium
- Low
- Informational

---

# Scope

This policy applies to:

- Documentation
- Infrastructure
- Network configuration
- Automation
- GitHub configuration
- Future source code

---

# Security Updates

Security fixes should be released as soon as practical.

Documentation should be updated alongside every security-related change.

---

# Third-Party Components

External software should:

- be actively maintained;
- receive regular security updates;
- use open standards whenever possible.

---

# Responsible Disclosure

Please allow reasonable time to investigate and resolve reported issues before public disclosure.

---

# Security Philosophy

Security is an integral part of the engineering process.

It is considered during planning, implementation, testing, deployment, and maintenance.

---

Thank you for helping improve the security of the Lifeg Platform.
